# 상세페이지 제작 가이드

**레퍼런스의 실제 크기·가로세로 비율·구역 배치·여백을 먼저 맞추고, 상품 사진과 문구를 교체한다.** 짧은 포스터형으로 압축하거나 임의로 재배치하지 않는다.

## 준비 자료
- 제품 사진 또는 사진 폴더 경로
- 상품명, 크기, 재질, 색상, 구성품
- 강조할 장점과 사용법
- 실제 배송·교환·반품 안내

## 디자인·문구 기준

- 일반 본문 좌우 여백은 54~70px. 구역 상단 여백은 80~195px로, 위 템플릿의 값을 유지한다.
- 메인 제목 72px, 구역 제목 약 54~58px, 본문 32px를 기준으로 한다. 제목은 자연스러운 2줄 이내로 다듬는다.
- 메인은 검정, 본문은 흰색, 설명·정보 구역은 연회색. Check Point는 빨강, 설치 번호는 파랑을 사용한다.
- 제목·설명과 사진을 별도 구역으로 배치한다. 넓은 빈 공간도 디자인의 일부이므로 줄이지 않는다.
- 제공 사진은 비율을 유지해 배치하고, 기존 문구·표가 불필요하게 걸쳐 보이지 않도록 사진 영역을 잡는다.
- 문구는 상품에 맞게 다시 쓰되, 실제 제품 형태·색상·구성은 유지한다.
- 크기·소재는 제공 자료에 근거한다. 미제공 성능·인증·배송비·배송일·반품 조건은 만들지 않는다.
- 배송 조건이 없으면 판매처 안내 확인 문구만 사용한다. 초안의 `확인 필요` 표시는 최종 이미지에 남기지 않는다.

## 완성·검수

- HTML/CSS로 구역 높이와 여백을 고정하고, 원본 사진을 배치해 PNG로 출력한다. 편집 가능한 HTML도 함께 저장한다.
- 긴 페이지 전체를 이미지 생성에 맡겨 레퍼런스의 비율이나 글자 배치가 바뀌게 하지 않는다. 새 연출 사진이 필요하면 해당 사진만 별도로 제작한다.
- 출력 파일이 **864 × 10,184px**인지 확인하고, 레퍼런스와 전체 흐름·여백을 비교한다.
- 한 글자만 다음 줄로 떨어지는 제목, 사진 잘림, 정보 겹침, 오탈자와 왜곡을 검수한다.
- 쇼핑몰용 크기 변경·분할이 필요하면 원본은 유지하고 별도 파일로 저장한다.
