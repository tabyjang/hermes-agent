# 투명 아크릴 티슈케이스 상세페이지

쿠팡 상세페이지 작업 기준에 따라 제작한 사용자 프로젝트 자료입니다.

## 구성
- `original-images/`: 사용자가 제공한 원본 제품 이미지 전체
- `deliverables/`: 편집 가능한 HTML, 렌더링 PNG, 파생 이미지, 제작 기록
- `상페가이드.md`: 제작 기준 원문
- `쿠팡_상세페이지_작업기준.csv`: Google Sheet 작업 기준의 CSV 내보내기

## 최종 규격
- 864 × 10,184px

## 보안
Google OAuth client secret, token, API key 등 인증 정보는 포함하지 않았습니다.
